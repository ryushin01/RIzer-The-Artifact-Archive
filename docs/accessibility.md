# KWCAG 2.2 점검 기록

- **점검일:** 2026-11-08 (0.5.0)
- **대상:** 공개 사이트 한국어·영어(첫 화면, 아카이브, 유물 화면, 404), 관리 화면(로그인, 대시보드, 유물 목록, 유물 편집, 주석 편집기)
- **환경:** 프로덕션 빌드, Chromium, 1280×800과 360×780
- **항목 번호:** 비공식 정리본 <https://a11ykr.github.io/kwcag22/> 기준. 인용·인증에는 공식 문서(KS X OT0003)로 확인해야 합니다.

## 어떻게 확인했는가

| 방법 | 범위 |
|---|---|
| axe (스토리 테스트, E2E) | 색 대비, 이름 없는 컨트롤, ARIA 오용 등 자동 검출 항목 |
| Playwright 측정 스크립트 | Tab 순회(초점 표시, 화면 안 여부, 다른 요소에 가림), 컨트롤 크기, 제목·언어, 중복 id, 콘텐츠 모델(`button` 안 대화형 요소, `ul` 자식), 레이블과 네임, 새 창 안내, 가로 넘침 |
| 코드 읽기 | 키 처리, 시간 제한, 움직임, 포인터 동작, 인증 흐름 |

**하지 않은 것:** 실제 화면 낭독기(센스리더, NVDA, VoiceOver, TalkBack)로 들어 보지 않았습니다. 자동화 환경에서는 낭독 결과를 확인할 수 없습니다. 아래의 '통과'는 위 방법으로 확인한 범위의 판단이며 인증이 아닙니다.

## 항목별 결과

표기: 통과, 부분(한계 있음), 해당 없음.

### 인식

| 항목 | 결과 | 근거 |
|---|---|---|
| 5.1.1 대체 텍스트 | 통과 | 유물마다 사진 속 실제 물건을 설명하는 `imageAlt`(한·영). 장식 사진은 `alt=""` |
| 5.2.1 자막 | 해당 없음 | 영상·음성 없음 |
| 5.3.1 표 구성 | 통과 | 관리 화면 표는 `th`와 제목을 씀. 공개 사이트에는 표 없음 |
| 5.3.2 선형구조 | 통과 | DOM 순서가 읽는 순서와 같음. 뷰어의 주석 번호는 목록 순서와 같음 |
| 5.3.3 명확한 지시 | 통과 | 안내가 모양·위치·색에만 의존하지 않음 |
| 5.4.1 색 무관 인식 | 통과 | 상태는 글자로도 표시. 현재 메뉴는 `aria-current`와 배경으로 구분 |
| 5.4.2 자동 재생 금지 | 해당 없음 | 소리 나는 콘텐츠 없음 |
| 5.4.3 명도 대비 | 통과 | axe 위반 없음. 사진 위 글자는 어두운 그늘 위에 둠 |
| 5.4.4 콘텐츠 구분 | 통과 | 섹션을 제목, 여백, 배경으로 구분 |

### 운용

| 항목 | 결과 | 근거 |
|---|---|---|
| 6.1.1 키보드 | 통과 | 모든 페이지를 Tab으로 순회. 딥줌은 화살표·+/−·0. 주석 영역은 끌기 없이 '보이는 영역으로 추가'와 숫자 입력으로 만듦 |
| 6.1.2 초점 이동·표시 | 통과 | 순회한 컨트롤 모두 초점 표시가 있고 화면 안에 들어옴. 점검 중 하단 고정 메뉴·저장 막대에 초점이 가리는 문제를 찾아 `scroll-padding-bottom`으로 고침. 주석 편집기의 SVG 초점 표시도 추가. 화면보다 긴 입력칸은 일부가 저장 막대 아래에 있을 수 있으나 전부 가리지는 않음 |
| 6.1.3 조작 가능 | 통과 | 공개 사이트의 컨트롤은 44px 안팎. 24px 미만은 글 속 링크 높이(20~23px, 너비 61px 이상)뿐이고 주석 목록 버튼은 24px로 키움. 사이드바 경계(폭 16px)는 같은 기능의 버튼이 따로 있음 |
| 6.1.4 문자 단축키 | 통과 | 한 글자 키는 뷰어에 초점이 있을 때만 동작 |
| 6.2.1 응답시간 조절 | 통과 | 공개 사이트에 시간 제한 없음. 관리 화면 세션은 12시간이며, 시연용 |
| 6.2.2 정지 | 통과 | 히어로 전환, 스크롤 연출, 안내 투어를 메뉴의 움직임 버튼과 운영체제 설정으로 멈춤 |
| 6.3.1 깜빡임 | 통과 | 초당 3회 이상 깜빡이는 효과 없음(히어로는 1.4초 교차 전환) |
| 6.4.1 반복 영역 건너뛰기 | 통과 | 첫 Tab에서 본문 바로가기 |
| 6.4.2 제목 | 통과 | 페이지마다 제목이 다름. 점검 중 404 화면 제목이 일반 제목이던 것을 고침(운영의 정적 404에서도 맞도록 2026-11-10 보완) |
| 6.4.3 링크 텍스트 | 통과 | 카드는 유물 이름, 새 창 링크는 '(새 창)' 표기(자동 확인) |
| 6.4.4 고정 참조 위치 | 해당 없음 | 쪽 번호가 있는 출판물이 아님 |
| 6.5.1 단일 포인터 | 부분 | 확대·축소, 주석 이동은 버튼 하나로 됨. 넓은 화면은 미니맵으로 이동. **좁은 터치 화면에서 사진의 임의 지점으로 옮기는 것은 끌기로만 가능**(주석이 달린 지점은 버튼으로 이동 가능) |
| 6.5.2 포인터 취소 | 통과 | 동작은 `click`(올릴 때) 기준. 사이드바 끌기는 놓을 때 확정하고 취소 시 되돌림 |
| 6.5.3 레이블과 네임 | 통과 | `aria-label`이 보이는 글자를 포함함(자동 확인). 점검 중 언어 전환 링크 "KO/EN"을 언어 이름으로 바꿔 고침 |
| 6.5.4 동작기반 작동 | 해당 없음 | 기기 움직임을 쓰지 않음 |

### 이해

| 항목 | 결과 | 근거 |
|---|---|---|
| 7.1.1 기본 언어 | 통과 | `<html lang>`이 언어판마다 다름. 영어판에 남은 한국어 내용과 언어 링크에 `lang` 표시 |
| 7.2.1 사용자 요구 실행 | 통과 | 초점만으로 화면이 바뀌지 않음. 검색 결과는 입력 초점을 유지하고 개수를 알림 |
| 7.2.2 찾기 쉬운 도움 | 통과 | 질문 섹션과 꼬리말이 언제나 같은 자리에 있음 |
| 7.3.1 오류 정정 | 통과 | 관리 화면 폼은 필드별 오류 문구. 저장 실패는 입력을 지우지 않음 |
| 7.3.2 레이블 | 통과 | 입력칸마다 `label` 또는 이름(axe) |
| 7.3.3 접근 가능한 인증 | 통과 | 이메일·비밀번호, 붙여넣기 허용, `autocomplete` 지정, 인지 시험 없음. 게스트 입장 제공 |
| 7.3.4 반복 입력 | 해당 없음 | 여러 단계에서 같은 값을 다시 받는 흐름 없음 |

### 견고

| 항목 | 결과 | 근거 |
|---|---|---|
| 8.1.1 마크업 오류 방지 | 통과 | 중복 id 없음, 콘텐츠 모델 위반 없음(자동 확인) |
| 8.2.1 웹 애플리케이션 접근성 | 부분 | axe 위반 없음, 커스텀 컨트롤의 키보드 동작 구현. **화면 낭독기로 실제 낭독을 확인하지 못함** |

## 이번 점검에서 고친 것

- 초점이 하단 고정 메뉴와 저장 막대에 가리던 문제(6.1.2)
- 주석 편집기 SVG의 초점 표시(6.1.2)
- 404 화면의 제목(6.4.2)
- 언어 전환 링크의 보이는 글자와 이름 불일치(6.5.3)
- 주석 목록 버튼 높이(6.1.3)
